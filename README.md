# Mindmap Note Writing

Plugin Obsidian d'ecriture en branche : une note est representee sous forme de carte mentale dont chaque noeud porte un veritable paragraphe.

Etat : phase 7 (deplacement de titres avec leur branche). La premiere case de la carte est toujours le nom de la note ; tous les titres Markdown, y compris un titre # unique, sont des chapitres. Les niveaux de titre se decalent peu vers la droite pour que la carte reste etroite. Glisser une case pour la deplacer : un apercu montre le resultat, la position horizontale choisit la profondeur, Echap annule. Cmd ou Ctrl + Maj + fleches deplacent la case selectionnee. Tab cree un sous-titre, Entree un titre de meme niveau, F2 ou clic sur une case selectionnee renomme (le nom de la note pour la premiere case), Suppr supprime avec confirmation.

## Installation avec BRAT

1. Installer l'extension communautaire BRAT dans Obsidian.
2. Commande "BRAT : Add a beta plugin for testing".
3. Saisir `Bigorneau15652/obsidian-mindmap-writing`.
