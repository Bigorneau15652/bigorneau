# Mindmap Note Writing

Plugin Obsidian d'ecriture en branche : une note est representee sous forme de carte mentale dont chaque noeud porte un veritable paragraphe.

Etat : phase 7 (edition de la carte). La premiere case de la carte est toujours le nom de la note ; tous les titres Markdown sont des chapitres. Tab cree un sous-titre, Entree un titre de meme niveau, F2 ou clic sur une case selectionnee renomme, Suppr supprime avec confirmation. Glisser une case ou Cmd ou Ctrl + Maj + fleches la deplacent avec sa branche. Cmd ou Ctrl + C, X, V copient, coupent et collent des titres en Markdown (textes et styles compris), Cmd ou Ctrl + D duplique. Le clic droit ouvre un menu avec ces actions et l acces a l apparence.

## Installation avec BRAT

1. Installer l'extension communautaire BRAT dans Obsidian.
2. Commande "BRAT : Add a beta plugin for testing".
3. Saisir `Bigorneau15652/obsidian-mindmap-writing`.
