# Mindmap Note Writing

Plugin Obsidian d'ecriture en branche : une note est representee sous forme de carte mentale dont chaque noeud porte un veritable paragraphe.

Etat : phase 8 (etiquettes). La premiere case de la carte est toujours le nom de la note ; tous les titres Markdown sont des chapitres. Tab cree un sous-titre, Entree un titre de meme niveau, Suppr supprime avec confirmation. Un double clic ou F2 sur une case ouvre une petite fenetre : titre, titre court (affiche sur la carte uniquement), commentaire et etiquettes ; un simple clic ne fait que selectionner. Les etiquettes (nom, couleur de fond, couleur de texte, en nombre illimite) se definissent dans le menu de la carte, entree Etiquettes ; elles n apparaissent que sur la carte, a droite du titre. Le titre court, le commentaire et les etiquettes d un titre sont conserves dans un commentaire invisible sous le titre. Glisser une case ou Cmd ou Ctrl + Maj + fleches la deplacent avec sa branche. Cmd ou Ctrl + C, X, V copient, coupent et collent des titres en Markdown, le clic droit ouvre un menu (dont Dupliquer, aussi disponible par la commande Dupliquer le titre sélectionné). Cmd ou Ctrl + Maj + Entree (ou Cmd ou Ctrl + Entree, si Obsidian ne le reserve pas) fait l aller-retour entre la carte et la note. Quand on passe dans la note sur un titre sans texte, une ligne vierge est ajoutee pour ecrire ; elle disparait si on la quitte sans rien ecrire. Depuis la premiere case de la carte, Entree et Tab creent le titre au debut de la note. La case selectionnee ressort nettement quand la carte a le focus, et reste discrete quand on ecrit dans la note. Les nouvelles etiquettes prennent d abord le vert, le bleu, le rouge et le jaune, puis un gris clair avec texte gris fonce ; ecrire un nom inconnu dans la recherche d etiquettes de la fenetre propose de le creer (Oui ou Non). Le contraste de la case selectionnee se regle dans les reglages du plugin. Un oeil apparait au survol d un titre de la carte : un clic masque le titre et ses sous-titres dans la note (le texte reste dans le fichier) et les grise sur la carte, ou les réaffiche ; ils restent copiables et déplaçables.

## Installation avec BRAT

1. Installer l'extension communautaire BRAT dans Obsidian.
2. Commande "BRAT : Add a beta plugin for testing".
3. Saisir `Bigorneau15652/obsidian-mindmap-writing`.
